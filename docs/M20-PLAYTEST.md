# M20 本地试玩

这是当前开发候选的操作说明，实际验收状态见 STATUS.md。`npm ci`、`npm run build` 后执行 `npm run preview -- --port 4173`，浏览器打开 http://127.0.0.1:4173/alpha2.html。不要直接双击 HTML。旧 Alpha/远征/哨站入口继续保留。

本地运行包为 `releases/fallen-star-0.20.0-rc.1.zip`，解压后在包目录执行 `node serve.mjs`，需要 Node.js 22.12+，不需要安装 npm 依赖。端口被占用时可用 `node serve.mjs 4190`，对应打开 http://127.0.0.1:4190/alpha2.html。服务器只监听本机。完整源码包为同目录的 `fallen-star-0.20.0-rc.1-source.zip`，在其 `project/` 中运行 `npm ci` 和 `npm run check`；模型审计另用 `npm run check:models`、`npm run check:items`。两个包均有SHA-256文件及包内逐文件清单，M15历史包未覆盖。

初始画布中选择种子与三种起始配装，再开始远征。规则时间只随正式行动推进，没有跳跃。A/D左右，W/S梯子，Space攻击，R施法，F拾取，Q治疗，X搜索，B背包，H指南；触屏使用同画布按钮。Tab可访问HUD热区，Enter激活；菜单内提供键盘导航。失焦、暂停、打开菜单、保存与读档停止连续输入。

背包可查看六装备槽与16格物品，选物品后选择公开可用动作和目标，确认执行。诅咒、视线、距离、库存等限制仍由正式命令决定。未知物品模型只表达本局随机外观；鉴定前不能据模型推断真实效果。地面、背包和商店使用同一资源身份。食物变质显示局部覆盖。

远征菜单包含设施交易、图鉴搜索、笔记、地图、日志、存录、新局、设置与帮助。日常界面均在画布内；导入使用系统文件选择，笔记/种子输入可借助隐藏外围文本桥接。笔记按正式命令保存，普通搜索不耗时间。切中英文不改变机械状态。

保存驻留当前浏览器的 `dungeon-descent.m15`。更换浏览器或共享前，在存录菜单导出 JSON；导入在本地验证，不上传。回放按既有命令边界显示历史，禁止回放中改变世界。M15及更早六种身份按原各入口恢复，不进行静默迁移。

低画质会使用真实简化物品、关闭阴影并限制DPR，保留接触与设施反馈。动作发生时物品页暂时显示场景，完成后返回。图形上下文丢失时显示外围错误提示，支持的浏览器恢复后重建画面；存录和逻辑时间不由图形回调修改。

开发回退入口为 `alpha2.html?ui=legacy`。当前不声称所有手机、Safari/Firefox或无障碍设备已验证；性能与已知覆盖缺口以最终验收报告为准。此本地候选不自动部署或上架。

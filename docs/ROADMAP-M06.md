# M03–M06 持续开发规格

用户授权以 M06 为目标持续开发，仅重大产品决策再暂停。基线为 M02C；本文件定义可交付小型版本的范围，不承诺尚未验证的真人时长或设备性能。

2026-10-11：上述小型版本范围已交付。实际实现、验收、失败修复和设备覆盖缺口统一见 `STATUS.md`，本文件保留开工规格。

## 范围与阶段

1. M03：复用当前骨骼制作守卫完整走/蓄力/攻击/受击/死亡，程序关节爬行者步态/扑咬/死亡，敌人实例按身份复用。建立带来源、目标、位置的行动表现收据；打击粒子和原创合成音效，暂停/回放不重放奖励或音效。武器和纸娃娃挂点保持有效。
2. M04：新远征场景，有限但真实的物品实例、拥有/地面/装备归属、背包容量、拾取/使用/穿脱/丢弃；药剂外观每种子变化，使用或鉴定揭示种类；鉴定卷轴；治疗、解毒、力量、护卫药剂及中毒/临时增益。危险和倒计时可读，所有耗时操作走统一命令。
3. M05：六个相连房间、三个区域的固定规模种子地牢；使用可组合遭遇/补给/守卫模板，梯子与主线位置变化。保证全图可达、初始安全、必需目标与补给存在。精英守卫守护终点遗物，取得后回到入口成功；支线提供风险与装备奖励。
4. M06：完整新局/种子/帮助/探索/背包/存读与文件导入导出/回放/死亡/结算流程，中英双语、触屏、音量/关闭音效、画质选项、资源生命周期与性能采样。保留旧演示入口和规则身份。

## 兼容与界面合同

- 新入口 adventure.html、新 expedition-1 规则与独立存档键。已交付 mine-1/room-1/dungeon-1 使用原实现、内容和历史身份；新增功能不以改变旧归档语义的方式接入。不将旧局静默迁移到新玩法。
- 新场景仍复用 GameSession 候选提交、种子重放和逐边界摘要。新模拟模块拥有远征内容/物品/状态调度，展示只能读取分离投影。隐藏药剂种类不出现在未鉴定 UI 投影中。
- 表现收据只包含已经发生且玩家可见的行动，动画/音效不可决定规则结果。无输入无规则推进；只保留当前仍按住的方向，绝不后台追赶。
- 骨骼和场景资源有明确 dispose；浏览器异步初始化可取消，读档失败不替换活局。

## 验收

- 各阶段完成后运行相关规则/表现测试，里程碑合并后检查全部旧场景、严格类型、构建及浏览器。
- 多种子地图可达/内容预算/安全起点；公开命令主线与支线自然通关；鉴定隐藏、物品单一归属、重复拾取/装备/使用拒绝原子性；状态到期、死亡、存读后续跑和每边界回放。
- 浏览器桌面/触屏模拟完整路线、模态阻断、暂停/释放/失焦、文件坏档、跨语言回放、音效关闭、画质切换。查看真实渲染截图；记录性能中位/P95/峰值及资源增长。
- 没有实际手机或硬件 GPU 时记录其覆盖缺口，不伪称真机通过。没有合法新资产需求则沿用当前 CC0 动作与程序几何，不采购资源或迁移引擎。
- 停止点为内容完整、可重复游玩的小型本地版本；多人、联网、商店发布、庞大法术/职业/饥饿系统不在本轮范围。作者自查与独立审查分别记录。

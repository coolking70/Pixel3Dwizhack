# M02B：可玩的 3D 哨站房间

用户已授权完成上一轮提出的下一次交付。本步范围：一个连续走廊与梯子相连的双层房间、一种敌人、装备拾取/五槽位换装、离开房间成功；可走、可打、可上下梯、可保存和回放。无主动跳跃。

## 规则与接口

- 复用 `GameSession → accept → advance`。新增命名 room 场景与独立内容/命令/规则身份；M01 mine 的默认行为、快照和存档身份保持原样，并用修改前实际保存的存档回归。
- 五槽位为 head/chest/legs/mainHand/offHand，有限装备清单、拾取后拥有、穿脱耗时，合法性全部在模拟入口验证。装备影响攻击/防御；UI 只接收公开目录、背包、装备与派生数值。
- 新页面 `/room.html` 使用相同公开视图。表现最多播放一个已提交动作，不排机械命令队列；松开、失焦、面板/回放/加载阻止后续行动。插值与动画回调不得写入模拟。
- 攀梯规则仍为层间原子行动；3D 将已提交结果表现为有限时间的攀爬。梯子锚点、横档间距、两段肢体 IK、收背和落脚由表现负责。暂停/读档/回放直接重建稳定端点，不保存动画中间帧。
- 角色衣甲独立槽位、身体分区可见遮罩、可关闭的程序像素材质，共用现有骨架。手持物保持 socket/grip 对齐。

## 验收与停止点

公开命令自然完成战斗→拾取铁甲→装备→攀梯→出口；非法穿脱/重复拾取不修改状态；多种子、存读后续跑、逐步回放一致；M01 测试与旧档通过。浏览器桌面/手机视口操作、暂停无未来命令、加载失败、触摸输入与无横向溢出。截图检查握持、梯子中间帧、装备外形和房间可读性。记录本机浏览器绘制/帧耗时样本，不能替代手机真机性能。

停止点为小型可玩闭环。随机地牢、通用资产导入、所有体型装备、完整状态异常/鉴定、Unity 迁移、发布部署不属本步。

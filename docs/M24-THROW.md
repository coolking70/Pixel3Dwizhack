# M24 自由投掷合同（实施中，未验收）

2026-10-12。根负责规则、会话和集成；旧六身份不修改。新 alpha3-1 / commands 7 / archive 1 复用 alpha2 普通命令，新增 a3:throw:itemId:floor:x，独立入口和存档。

目标必须是当前层、已探索且当前可见的内部格，离玩家 1–5 格。所有未装备的背包物品可投。睡眠时拒绝。提交前完成验证；拒绝不改变状态。规则遍历从玩家到目标的整数格：关闭的门先阻挡并落在门前；其后首个活敌人截获；抵达目标后才命中该格已揭示设施（同格按 id）。未揭示陷阱不参与投掷碰撞。一般设施不阻挡途经抛射。碰撞顺序不依赖渲染。

药瓶在任何有效落点破碎消耗；命中敌人或设施时才执行自身投掷效果，不适用或免疫仍完成投掷。只有可观察的有效效果才鉴定药瓶。其他物品命中敌人施加固定 7 点物理撞击（仍经过护甲/抗性），随后落地；法杖不施法、不耗充能、不鉴定。空地不施加效果。所有落地物品保留实例 id、属性与唯一归属，位置为实际碰撞落点。每次成功投掷消耗 14 tick，缓慢翻倍，统一 advance2 推进；动画不推进时间。

alpha3.lastThrow 保存本次命令的源 id、目标格、实际落点、公开碰撞对象、是否消耗及修订号，包含于摘要/存档/回滚。普通成功命令清除收据；查询和渲染不写入。公开投影只展示此已发生的公开碰撞结果，接触/效果动画据此呈现。预览不探查物品真名、效果或未揭示目标。

验收：输入语法/范围/遮挡/装备/睡眠拒绝原子性；空地/敌人/门/设施/免疫/无充能法杖；全部 45 定义落地或消耗所有权；自然正式命令存读、逐步回放、seek、续录；旧身份拒绝新命令，新旧存档隔离；动画四阶段和三视口另行浏览器覆盖。受控夹具不得计为自然路线。发现严重缺陷停止冻结而非改黄金掩盖。

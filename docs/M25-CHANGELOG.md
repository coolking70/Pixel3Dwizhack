# M25 交互候选 0.25.0-rc.2

本轮从完整0.20.0-rc.1推进M21–M25。实际测试与缺口见M25-ACCEPTANCE.md及STATUS.md；变更列表不代表所有设备验收通过。

- 公共能力查询统一物品与设施动作、目标、公开禁用理由及未知效果提示。查询不推进时间或消耗随机，确认重新核对修订。
- 默认场景改为直接点击：已知地面逐格走、物品拾取、敌人攻击、门和梯子操作。未锁门按正式命令先开后走，收费设施与锁门保留明确情境选择。危险与生命周期变化停止旧意图。
- 六装备槽、十六格背包点击进入独立3D详情；目标选择由公开候选高亮，世界瞄准支持指针、触摸目标切换、键盘和手柄边沿输入，选中远目标时相机同时纳入玩家与目标。原生UI仍在同一画布，旧按钮和HTML回退入口保留。
- 新alpha3-1/commands7使用独立入口与保存键。增加同层地面投掷、确定性首碰撞与实际落点收据；普通物品落地、药瓶破碎、投掷法杖不消耗充能。四阶段动画只读取结果。
- 新规则有独立自然黄金和双跑/回放工具；旧六身份及其黄金不替换。CI新增三尺寸直接交互及Firefox/WebKit项目，配置存在不等于本地兼容通过。
- 135个已有GLB复用，没有扩增物品、职业、怪物、跳跃或实时战斗。

已修复本轮发现的锁门文案黑画布、取消焦点误提交、无实际药效却鉴定、悬停覆盖已选轨迹、手柄瞄准误走菜单导航、横屏确认遮挡、竖屏远目标不可触达和旧按钮入口轮询干扰WebGL取消。角色/物品预览也按纵横比与包围体保留边缘。首轮失败和原反例复测分别保留，不将有限审查称为全面设备认证。

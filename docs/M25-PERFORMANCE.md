# M25 生命周期与资源采样

脚本 `scripts/m25-lifecycle.mjs` 从正式原生新局进入，以初始干粮为公开对象，重复背包→独立详情→自身或世界目标→取消详情→取消背包→世界。两次预热后每视口记录100次；每阶段断言tick和revision不变，不读取或修改隐藏世界。

三个视口分别为1440×900、844×390、390×844。逐阶段记录共享renderer的geometry/texture计数、CPU提交耗时、draw call、三角形、条件可用的JS heap与自动化转换时间，给出中位/P95/峰值；WebGL create/delete调用计数区分主canvas与离屏缩略图，不能当成GPU内存字节或逐场景资源归属。每周期世界边界额外强制GC并记录CDP heap、DOM节点/监听器，输出完整时间序列、每10次窗口、上升/下降次数、连续非递减长度和斜率。增长信号须结合原始曲线判断，不能仅比较最终差值。

完整验收须使用固定生产构建、独占设备负载，运行命令例如：

```powershell
node scripts/m25-lifecycle.mjs --out <外置证据目录> --url http://127.0.0.1:4185/alpha3.html --cycles 100 --exclusive
```

仅3次功能自查不要求独占：`--cycles 3`。超过3次时脚本要求显式`--exclusive`，它只声明维护者已调度，不会自动检测或停止其他进程。报告包含源码SHA256、实际入口脚本SHA256、浏览器/CPU/OS/GPU renderer、视口与方法限制。探测Playwright Firefox可执行文件是否存在，但不启动Firefox；存在不代表兼容通过。

初始状态（历史记录）：此时仅完成采样器，100次与性能尚待执行；实际完成结果见下文。真实触屏、Firefox兼容、GPU完成时间和GPU字节仍不由此脚本覆盖。

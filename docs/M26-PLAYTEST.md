# M26 本地试玩

候选版本0.26.0-rc.1，默认入口alpha4.html。实际通过与保留项目见[验收](M26-ACCEPTANCE.md)及[STATUS](STATUS.md)；本说明描述操作，不表示所有设备已验收。

## 启动与保存

运行包解压后，用Node.js 22.12+执行 `node serve.mjs`，访问 http://127.0.0.1:4173/alpha4.html；端口占用时执行 `node serve.mjs 4174`。不能双击HTML。完整源码在project目录执行 `npm ci`、`npm run check`、`npm run dev`，打开终端地址下的alpha4.html。

新局使用alpha4-1 / commands8 / archive1，浏览器保存键dungeon-descent.m26。alpha3.html和alpha2.html继续使用原规则和保存键；旧完整档须在对应历史入口导入；跨身份导入会拒绝并保留活局，不迁移或重算成新掉落规则。分享/换浏览器前从菜单的存录页面导出JSON，文件仅在本机验证。

## 操作

- 直接点地面移动、点敌人攻击；有明确上下方向的梯段只跨一层。遇到危险或取消后需要新的明确操作。
- HUD只有“角色与物品”管理入口。人物页显示六槽装备，背包页只列未穿戴物品；属性页集中显示角色状态。可筛选装备、消耗品、工具和任务物品。
- 新规则装备不占普通16格，但计入重量；背包满时卸下会拒绝并提示先腾格。旧规则仍如实按全部携带物品计算容量。
- 点物品进入详情，合法操作及目标来自当前公开查询。可重复使用后保留详情，消失/丢下后回就近格；换装回相应槽位。未知属性显示“?”。
- 单件露出的地面模型可直接点取指定物品；重叠或×N标记打开选择器。指针/键盘焦点高亮对应模型，长按只查看；“全拾取”是显式逐件操作，满格、危险、受伤、失焦或取消会停止后续拾取。
- Esc或手柄Start打开菜单；普通探索没有Pause/Resume。失焦撤销未提交输入和确认，已提交动作保持结果。返回窗口的激活点击只聚焦，下一次全新输入才行动。
- A/D或左右移动，W/S或上下攀梯，Space攻击，B打开背包，H指南。旧按钮界面在 `?ui=buttons`，外围DOM回退在 `?ui=legacy`。

触屏视口模拟不等于手机验收；Firefox、Safari、Android及实体手柄的实际状态见验收矩阵。遇到问题请附版本、规则身份、种子、视口、入口参数、导出的完整档和复现步骤。

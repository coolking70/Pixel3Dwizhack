# M01 架构决定与状态清单

当前 M16 表现扩展合同见 `M16-INTEGRATION.md`。`src/game-ui` 和 `src/visual` 只消费公开投影，`src/balance` 通过会话做正式命令自然实验；均不改变下文既有机械身份。模型/缩略图/字形纹理、交互收据/相位、画布热区/焦点均为可销毁表现状态，不保存、不计摘要、不具有规则写能力。缓存异步结果以当前公开装备/当前视图重核，失败沿用占位并标记，不回滚规则。

本文件按里程碑保留历史合同；当前 M06 增量见末尾，历史章节中的“尚未实现”只描述当时阶段。

## 边界

`GameSession.submit` 是活局唯一机械命令入口。模拟的 `accept` 对旧世界进行结构化复制，运行玩家效果与 NPC 时间调度后返回候选；会话完成候选摘要和新历史构造再发布。拒绝、异常不修改旧局。当前世界很小，因此优先使用完整复制；尚未引入窄写集或监听器回滚。

会话不接收显示文案，模拟不依赖 Vue、DOM、存储或墙钟。`inspect` 复制并过滤公开字段；显示可重复查询，不消费随机或写日志。UI 中的状态通知属于会话显示，不参与机械摘要。中文和英文共用语义事件键与原始数量。

内容固定为 `MINE` 声明，首阶段不设计通用插件系统。固定地形已可通过正式输入走到遗物并返回；随机只影响金币数量和玩家伤害。没有声称已经实现随机地牢生成。

## 数值、空间与时间

机械位置、生命、资源、种子、tick 均为整数。坐标为 `(floor, x)`：三条水平走廊，范围 x=1..24；x=17 连接第 1/2 层，x=8 连接第 2/3 层。移动一格，不支持跳跃、落差、斜坡或单向平台。碰撞只查询逻辑位置，与绘制尺寸独立。

玩家效果先结算，然后 `advance` 消耗声明成本；同一截止时间的 NPC 按 id 从小到大行动。未到期的 NPC 保留 `nextAt`；离开玩家所在层或视野的 NPC 不产生效果，但其行动期限照常更新，返回后不会补发攻击。死亡发生在实际事件 tick，后续输入拒绝。胜利检查发生在移动成本提交之后。

xorshift32 的位运算采用 JS uint32 语义；输入种子严格限制 1..4294967295，零值拒绝。小范围随机使用余数映射，存在极小模偏差，这不承担公平抽奖用途。所有规则抽样只从 `world.rng` 获取。火光等表现变化使用渲染时间，既不调用规则 RNG，也不改规则状态。

## 存档与回放

存档为 `{ identity, seed, history, world }`。规则行为 `mine-1`、命令协议 1、存档格式 1 分别有身份；内容使用完整机械声明的规范化指纹。规则变化必须修改规则身份，机械内容变化自动改变内容指纹，文案变化不改变身份。

导入顺序：文本预算 → JSON → 深度/节点预算 → 精确顶层字段 → 身份 → 种子/历史结构 → 隔离会话逐命令重放与摘要 → 最终世界逐字段规范化对比 → 发布候选。快照不作为可信起点使用，因此实体关系、期限和资源也必须与正式命令产生的世界完全相同。额外快照字段同样拒绝。

完整 FNV-1a 摘要是不同步定位工具，非防篡改承诺。最终世界使用完整 canonical JSON 比较，不只相信导入文件自报摘要。回放不设检查点或 Worker，从可信种子重新执行前缀，成本随命令数增长。

浏览器存储适配器使用单次 `setItem` 替换整个封装，依赖 Web Storage 单键写入语义；配额等失败只报告，不重做机械命令。手动保存避免试玩行为覆盖用户已有存档。

## 本阶段限制

没有长动作中间态、暂停动画插值、seek 检查点、录像分支、内容模块卸载或跨标签同步。连续按住每 150ms 请求一个动作，节奏不受操作系统重复速率影响；新命令在下一次渲染前不预排。保证松开后无未来提交，不保证在同步指令内部打断。真实设备输入延迟和性能分位数留待后续实测。

## M02B 扩展

上述章节保留 M01 合同。`GameSession(seed, scenario)` 新增 `room`，默认仍为 `mine`。两者调用相同 `accept/advance/inspect`；M01 不增加 world 字段，不改变 `mine-1`/commands 1 身份。实际旧档夹具 `tests/fixtures/mine-v1.json` 来自修改前生产页面执行 16 条正式命令后保存，加载时每条旧摘要必须匹配。

房间使用 `room-1`/commands 2，内容身份包括 ROOM 与 GEAR。只有 room 新世界含 `scenario:'room'`、玩家 inventory/equipment。`equip:<gearId>` 和 `unequip:<slot>` 经统一入口校验拥有、槽位与重复状态；成功耗时 8 tick，攻击/防御由所装备条目派生。卸下物品仍由背包拥有，地面拾取只发生一次。本步为有限唯一装备清单，非通用实例/容器系统。

`inspect` 给 room 附加分离的目录与派生战斗数值；3D UI/renderer 不导入机械内容或模拟执行器。`restore` 必须与当前会话场景一致；静态 `fromArchive` 按独立身份创建隔离候选。room 与 mine 使用不同浏览器存档键。

呈现最多持有一个 `{from,to,motion,start,duration}`，已接受命令的机械结果先提交，再播放有限插值。动作忙时拒绝新输入，无命令积压；方向重复间隔 320ms，普通走步表现 260ms，攀爬表现 2600ms。松开停止后续提交；失焦、暂停、保存/读档、回放直接结清到稳定端点，不执行补时、额外命令或命中奖励。回放只看边界，非动画录像。

角色基础骨骼/内衬与刚性装备共用 M02A。head/chest/legs 外观独立选择；身体遮罩隐藏被覆盖的躯干前后面、头发、前臂与胫部。可选 8×8 程序灰度纹理只影响材质。攀梯时剑盾挂背，脚趾与掌心以两段 IK 对齐横档，停留/摆动阶段交替；梯口活板在表现期间打开，稳定端点关闭。没有跳跃、落差物理或 IK 驱动位移。

新增状态归属：装备/背包由模拟拥有并保存；统计值与外观由投影派生；动画、IK、材质、相机、GPU 实例与资源缓存由 renderer 拥有且不保存。静态房间按材质实例化批绘，梯口活板保留为可动网格；停止动画后不持续 requestAnimationFrame，拆除时释放几何、纹理、混合器、骨架、实例和观察器。

## M02C 扩展

`dungeon` 为第三个明确场景，入口与存档键独立。`dungeon-1` / commands 3 / archive 1 的内容摘要包含 DUNGEON 与 DUNGEON_GEAR；后者扩展旧 GEAR，不修改 room-1 的目录或摘要。旧 room 快照夹具在修改前由正式 GameSession 命令产生，恢复逐历史验证后重导出相等；不是手写黄金。mine/room 不出现新敌人字段，旧行为保持。

三条走廊宽 24，梯口分别 x=10/17，房间名由公开 map.rooms 提供。新地图与有限物品仍为固定内容；UI 不导入内容文件。地图预知三间房，未访问名称显示未探索；实体与意图仍只投影当前楼层可见者。

新敌人 `kind/damage/intent` 均由模拟拥有、保存、摘要。守卫在四格内开始接近，相邻的到期行动写入锁定坐标 intent，下一次 30 tick 截止攻击锁定点 ±1 格；玩家效果先结算，故恰在截止行动中退离也能闪避。离开楼层时仍清除到期 intent，但不会攻击新楼层玩家；守卫死亡后不再调度。意图与动画无关，停机时不自行结算。渲染器只画公开标记和倒计时。正面硬扛、使用药水与闪避都是合法路径。

3D 页将旧 320ms 重复定时器替换为 MotionInput：最多保存一个仍按住的方向意图，当前动画结束后才尝试下一次授权行动。危险、松开、失焦或显式 stop 清除意图。渲染完成回调不能自创意图；无按住状态时只释放 busy。M01 输入器仍为原实现。

攀梯改为 3 秒有限呈现：前后各 12% 用于转身与姿态融合，中间用平滑插值连接位置并维持 IK。接触误差仅在完整附着区间有意义。攻击混入/混出待机姿态；武器握点随骨骼自动保持。盾板轴向与握柄分别建模，背部 socket 补偿板面旋转。纹理开关同时控制角色和环境；场景按材质与实例颜色合批，三间房使用不同色调和地标。

## M03–M06 扩展

`expedition` 为第四场景，`expedition-1` / commands 4 / archive 1；内容摘要包含 EXPEDITION 与 EXPEDITION_GEAR，独立键 `dungeon-descent.m06`。旧三场景调用原模拟分支，历史世界不增加远征字段。新增 `dungeon-v1.json` 夹具来自改动前的正式会话命令；三种旧身份均逐摘要恢复。

新场景由 `expedition-map.ts` 建立地图、物品和敌人，由 `expedition.ts` 独立拥有规则时钟和投影。地图固定六层、每层 x=1..24 连续可走；五个梯口按种子变化，门厅/军械库/墓室各两层，遭遇采用 supply/nest/watch 三种模板。模板配置不同敌人数和种类；补给、装备和圣坛放在确定的入口或端部。起点无近敌，精英守护者和遗物各一个；不是任意拓扑、跳台或无限生成系统。

物品 id 在新局单调分配。`owner` 为 bag/ground/spent 三选一；装备槽仅引用背包实例，不转移拥有权。已穿戴物品不能直接丢弃。背包容量 16 含穿戴物品，任务遗物例外。相同 gearId 可有不同实例和品质；+1 主手增加攻击，其他槽位增加防御。旧 Player 的装备、库存及药水计数在远征公开投影中由实例派生；远征世界中的旧 potions 字段是固定兼容字段，不参与新规则，实例归属是唯一来源。

药剂效果存在完整存档中；公开 ItemView 只有瓶色，鉴定后才含 effect。瓶色映射由种子打乱，同局同色同效果；治疗初始已知。鉴定卷轴或饮用更新全局知识，重复鉴定拒绝。ground/nearby/bag 均经过同样过滤；文件备份是有意包含完整世界的独立通路。

状态期限、圣坛 used、击杀/拾取计数和物品归属都在候选世界内保存、摘要和回滚。药剂/圣坛效果先发生，再支付行动时间；状态到期先于同刻毒素脉冲，毒素先于同刻按 id 排序的敌人。重复中毒刷新 until，不重置下一脉冲；毒素在到期点不再脉冲。远离楼层的敌人仍更新 nextAt，但不造成命中或补时。守卫攻击锁定点 ±1 格，爬行者相邻直接攻击。

`beats` 是最后一次已提交行动的确定性表现收据，记录来源/目标 id、位置、tick、命中量；在世界中保存并参与验证。UI 仅在新的 submit 成功后播放，sync/restore/replay 不播放。玩家 id=0，毒素来源=-1；敌人 id>0。渲染按攻击收据分段，接触时刻统一为每段 45%；粒子、受击、音效使用同一采样定义。守卫复用既有骨骼和 CC0 动作，爬行者为程序关节。演员按 id 复用，离开可见集合/死亡后释放；粒子最多 8 个实例。源攻击片段仍为一种单手劈砍，不是全武器动作库。

音效为原创 WebAudio 短音，默认关闭，需明确点击启用。单次最多 8 个声音，暂停/失焦/面板/读档/回放停止已排程声音，卸载关闭上下文。音量、阴影/DPR、语言等偏好只在 UI 存活，不进存档。低画质关闭阴影、DPR=1；普通模式 DPR≤1.5。阴影灯随当前走廊移动，避免深层超出早期固定阴影范围。

源劈砍 clip 约 50% 前仍在抬手，实际前伸接触位在 57.5%；`chopPhase` 将它映射到表现段的 45%，守卫蓄力使用源 45% 的抬手姿态。这是基于当前固定骨架和动作的适配参数，换源动作应重新采样验证。跨种子恢复可能重用同一个敌人编号，因此演员复用同时检查种类和精英标记，不匹配时释放重建。

会话回放缓存每 32 个已验证命令存一个私有 checkpoint，最多 32 个加初始状态；缓存不序列化、不作为导入的信任起点。冷/热、正/反 seek 均应与从种子重放相等；restore 替换整个缓存，submit 只追加历史。完整文件导入仍从种子验证全部历史和最终快照。异步文件结果由 token 绑定会话边界，换局/成功行动/回放/其他导入使旧结果失效。

## M07–M10 Alpha

`alpha.html` 是第五种规则场景，独立 `alpha-1` / commands 5 / archive 1；内容摘要包含 ALPHA 与 ALPHA_GEAR，当前为 `30b48cf5`。独立存档键 `dungeon-descent.m10`。四种历史场景仍逐摘要恢复；M06 的 42 号自然支线 341 行动被捕获为 `expedition-v1.json`。旧 expedition.ts 只为新增 GearId 收紧了键类型断言，没有行为改动。Alpha 规则在 alpha.ts 分支独立演进，避免为了共用大量条件而扰动已交付模拟。

`World.alpha` 唯一拥有起始配装/是否已选择、mana/manaAt、双梯连接、门闩 open/locked、拉杆 used、补给箱 used/rewards；全部保存、摘要、重放。原 `World.expedition` 继续拥有物品、状态和六层主题。Alpha 生成器以冻结的 M06 初始物品合同为基础，独立设置十个梯口、四个中部门闩与拉杆/箱子、两种新增敌人及其护甲。没有跳跃或可落入的地板缺口。

首个 `choose:vanguard|breaker|channeler` 不消耗 tick，推进一次 revision，替换三个起始槽的物品定义。第一次普通行动也锁定选择，后续 choose 拒绝。剑近战耗时 10，锤 20 并抵消 4 护甲，其他近战 12。`cast` 要求持杖、3 法力以及 5 格内可见目标，耗时 18，基础伤害 14 加 0–2 波动，无视护甲；这是独立于装备近战伤害的法术。法力每 20 tick 回复 1，上限 12；查看、暂停或实际时间经过都不回复。

Alpha 统一时钟同刻顺序为状态过期 → 法力回复 → 毒素 → 存活敌人 id 顺序。守卫锁定格 ±1，咒术师只锁一格、抵消一半玩家防御（整数向下取有效防御），游击兵在同次攻击后尝试退入一格合法空地。意图在换层后仍到期清除，不攻击别层；闭门阻挡路径和视线，包括已排程施法。普通门可开关，有锁门由关联拉杆永久解锁并打开；不能在有人站在门格时关门。

补给 `cache:<id>:pay|force` 选择花 12 金币或 8 生命，耗时 10；生命不足以存活时拒绝。奖励物品 id 在新局分配，开启时从封存状态置于地上，因此满背包不吞奖励。未开启奖励 id 不进入公开视图。完整文件备份仍有意包含完整世界；导入信任来源始终是种子和合法历史重建。

Alpha 公开投影包含派生的攻击费用/施法范围/资源、已探索门、当前视线内拉杆/箱子；箱子投影去掉 rewards。闭门后方未探索格不被 reveal；当前走廊的未知地板用暗色连续底面表示，不泄漏后方敌人与物品，也不会画成跳台缺口。小地图由公开 explored/ladders/doors/player 绘制。

呈现层新增 `mode:spell` 的表现收据，供有限投射物与独立合成音高使用。同步、保存、导入、暂停、回放都立即结清并隐藏投射物；没有投射物碰撞驱动伤害。游击兵先完成接触再呈现后撤。剑采用原创前刺 IK，锤沿既有 CC0 轨迹，低矮目标使用低位姿势；站立攻击按实际鞋底顶点接地，行走按支撑/摆动周期求腿部 IK，支撑脚不随身体水平滑动。原 `/character-lab.html` 仍可查看未经这层战斗适配的源动作。

`vanguard.json` 为原创受限模型数据包：明确 rigId、骨名、尺寸/局部或绑定姿态坐标、身体区域、材质颜色、遮罩、握点；启动前校验有限部件数和数值/引用。角色与装备可独立替换，但不是通用 FBX/glTF 骨架重定向。检查场 `/combat-lab.html` 不持有游戏世界。

分发：`npm run release` 检查模型配方、严格类型/生产构建，再生成固定 ZIP 时间戳、排序文件、逐文件 SHA-256 与构建输入清单。`serve.mjs` 无 npm 运行依赖，监听 127.0.0.1，根入口重定向 Alpha，拒绝越目录路径，只支持 GET/HEAD。规则身份是存档合同，包散列是交付校验；散列清单不声称数字签名或安全认证。


## M11–M15 Alpha 2

第六种规则场景 `alpha2` / `alpha2-1` / commands 6 / archive 1，`alpha2.html` 与 `dungeon-descent.m15` 独立于 M10。身份包含 ALPHA2_CONTENT 的全部机械定义；本地化名称和说明不进内容散列。旧五种规则分支及黄金档不改；新模拟函数单独分派，避免引入旧规则条件漂移。

Alpha2State 唯一拥有实例、装备引用、外观分配、分层知识、玩家笔记、饱食/法力、状态、怪物原型关系、设施与库存/金币、分段/门/梯路、统计与语义日志。整个世界随合法历史保存。节点的 Position 仅保存 x/floor，不从 Enemy 或 Facility 的整对象扩散其他字段。日志与收据入口不保留 undefined 字段，保证 JSON 往返与规范化摘要完全一致。

`alpha2-map` 负责种子世界与稳定实例，`alpha2-shared` 负责只依赖世界的共有派生与事件，`alpha2-effects` 解析目标并调度效果注册表，`alpha2-clock` 是唯一逻辑时钟，`alpha2` 提交动作，`alpha2-view` 生成脱离世界引用的公共投影。消费、所有权迁移、知识改变、NPC 行动、拒绝均在候选副本完成。使用项目现有 GameSession 的完整历史验证和有界回放缓存。

协议为旧通用方向/攻击/拾取/穿脱等加 `a2:use:<id>:<action>:<target>`、设施/交易/搜索/笔记命令。目标 key 为 self、e 生物、i 物品、f 设施、d 门。精确正则、整数位数/文本长度、解码及控制字符检查阻止无界或不完整命令；后续目标解析校验当前归属、视野、距离和视线。UI 不凭真名选择隐藏效果。

真名按定义识别，BUC/强化/充能按实例识别，笔记为最多 120 字的玩家文本。备注命令耗时 0、修订 +1，随回放保存；搜索字符串仅为 UI 状态，不存盘、不耗时。回放投影使用该边界知识，不读活局知识。正常 view 不含 assignment、隐藏奖励、全图怪物或真实未鉴定定义；备份文件有意保留完整世界，但只信任种子历史重建结果。

状态来源存语义引用字符串，不存翻译正文。公开状态来源和日志名按边界知识解析；没有根据未来鉴定重新推演过去。清除期限 → 法力/饱食 → 持续伤害 → 敌人 id 是同刻固定顺序。饥饿伤害不被毒抗抵消。睡眠会清除敌人意图；死亡后不追加新的燃烧/迟缓状态。不同元素、物品腐蚀和装备抗性各有职责。

渲染器继续读取 PublicView；Alpha 2 的旧 alpha/expedition 字段只是即时派生适配视图，不在新世界中维护第二套机械真相。新公开 alpha2 字段提供详细物品、动作费用、已发现图鉴、区域和设施；原始世界不传到 renderer。受限骨架增加五种懒创建武器变体，弓的盾收背、另一手拉弦，所有变体使用同一握点和梯上收背合同。敌人演员复用同时比较 archetype id；新轮廓/色彩/比例只影响外观。

Alpha 2 仍一次只显示一个动作，连续输入只保存仍按住的方向；弹窗、失焦、暂停、回放、存档结清表现，音效取消。备注零 tick 直接同步，不播放战斗。所有笔记使用 Vue 文本/输入绑定，无 HTML 解释。

运行包与源码包分开生成：前者含八入口和本机服务器，后者含 src/tests/public/scripts/docs/锁文件和配方。ZIP 固定时间与排序，逐文件 SHA-256；二者均有校验文件。历史原始原型参考不随源码包重新许可或分发。实际性能采样和发布散列见 STATUS 及 releases 清单。

## M16–M20 表现与实验边界

规则身份与上述存录合同不变。`src/game-ui` 在 RoomRenderer 同一 WebGL 画布上合成原生菜单、HUD、物品缩略与公开角色预览；Vue 负责会话编排、文件/IME桥接、生命周期及错误兜底。`CanvasInputRouter` 将热区/键鼠/触屏转为语义回调，只有 Game 的正式提交入口写会话。搜索、菜单游标、画质与缓存均为纯表现。回放只读，busy 动作期间不会排队补交输入。

`src/visual/items` 的公开 resolver 仅按可见身份/随机外观键返回资源；GLB 模板由有界身份集合缓存，实例共享几何材质并独立克隆变换，装备按槽和骨绑定、恢复身体遮罩，异步结果用修订/销毁状态作废。物品三档LOD为不同实际几何；普通近处LOD0、远处LOD1、低画质LOD2。食物变质覆盖层只读公开 freshness，不改变共享材质。缩略图按公开外观及状态缓存，非逐帧重复运行45个场景。

`src/visual/motions` 从 accepted 命令的 before/after PublicView 派生版本1只读表现收据；袋内使用与穿脱在兼容字段中记录公开物品、目标key和公开目标物品。准备、接触、效果、回稳均由墙钟驱动纯呈现；规则早已原子提交。真实模型握点、工具尖端、口部、门铰/门把、杠杆与箱盖约束只改骨架和网格。动画没有命令/随机能力；失焦、暂停、存读、回放、图形失效均落到稳定after，WebGL恢复仅重建显示资源。

`src/balance` 使用正式新局与只读冻结投影，代理只能返回合法命令候选，无世界写引用。m16-public-1旧三策略冻结保留；m17-experiment-1加入自然探索和配对策略消融。CLI记录全部命令（含拒绝）、tick、机械摘要及输入散列，按批保存可重放trace。共享seed的九配置使用seed聚类配对置信区间，不把相关配置当独立样本。表现改动以相同配置完整trace和最终摘要精确比较；算法策略版本变化不得冒称游戏数值变化。

具体测试、独立审查边界及性能限制见 M20-ACCEPTANCE.md 和 STATUS.md，不能从本架构说明推定设备验收通过。

## M21–M25 直接交互与 Alpha 3

`core/action-types.ts` 定义公开动作、目标和表现意图。会话的 `queryActionOffers/queryTargets/queryContextOffers` 只计算公开可尝试能力，返回当前 revision、禁用原因和正式命令；不推进时间、不采样随机、不探测隐藏效果。未知物品按公开类别给 uncertain，不能凭真名缩小目标集。确认时 Game 重新查询同一来源、动作、目标及 revision，再调用既有 submit；回放不给可写候选。

`interaction/intent.ts` 仅持有瞬态路线和设备按住状态，依据 PublicView 中已发现走廊、门和梯子，每次完成表现后最多提交一个正式动作并重新判定。命中测试使用实际摄像机和 CSS 坐标的公开代理；物品与设施重叠时可点击各自露出的部分。出现敌人、受伤、异常、换层、菜单、失焦、存读或新意图均停止旧路线。持续方向释放后不补行动，主动跳跃仍不在范围。

直接模式的同画布 UI 以世界、背包、独立物品详情、目标选择及情境确认为层次。6 槽/16 格不常驻动作矩阵；GLB 大预览与缩略只按公开身份解析。ItemInteraction 的 source/action/target/revision 全为可丢弃表现状态，不进机械摘要或存档。目标箭头循环与指针选择走同一查询结果；GamepadInput 只转换输入边沿，取消后要求摇杆回中。旧原生按钮模式 `?ui=buttons` 和外围 `?ui=legacy` 保留。

`balance3` 单独版本化基础和一次自然投掷探索策略；只通过正式新局、公开查询和 submit 运行。它的 double-run、逐尝试回放、来源 SHA 和自然通关黄金与旧 9000 trace 对照分开报告。新身份摘要不可冒充旧规则回归。M25 运行分发增至九入口，默认 Alpha 3；实现说明不等于验收完成，真实结果仍以 STATUS 和 M25-ACCEPTANCE 为准。


## M26 Alpha 4 与交互导航

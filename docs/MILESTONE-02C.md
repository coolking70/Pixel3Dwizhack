# M02C：三房间地牢切片

用户已授权继续上一轮计划。本步以 5–10 分钟首次探索为设计目标，实际时长仍需用户试玩验证。

## 范围与接口

- 新入口 dungeon.html：门厅、旧军械库、封印墓室三间纵向相连的完整走廊；两架梯子构成主路线，军械库左翼为可跳过的装备支线。取得墓室遗物后返回门厅出口；无跳跃或需要跨越的缺口。
- 新 dungeon-1 身份、命令版本 3、独立内容摘要与存档键。保留 mine-1、room-1 的确切行为和历史验证，新增装备不能改变旧装备目录摘要。
- 爬行者与慢速守卫两种行为。守卫先蓄力，再在下一截止时刻攻击蓄力时锁定的位置；移动两格或换层可避开。倒计时只随玩家行动推进。危险提示只读取公开敌人意图。
- 钉锤（高攻击、低防御）与塔盾（高防御、低攻击）形成组合取舍。五槽位比较显示攻防变化，拾取、穿脱、喝药均通过语义命令。
- 三房间探索、战斗、支线、药水、遗物、返回出口、死亡、跨房间保存和只读回放形成闭环。场景名、危险和路线提示中英双语。
- 改善按住移动的呈现衔接，渲染繁忙时仅保留当前仍按住的意图；松开/失焦/危险后取消，不排队。攻击与攀梯做有限姿态过渡，挂点和手脚约束仍为表现。
- 延续当前块面风格，增加武器/盾牌轮廓、守卫和房间地标，统一程序像素材质。保留原有动作来源与许可。

## 验收与停止点

通过公开命令验证多个种子主线及支线通关、守卫蓄力/闪避/命中/死亡、装备取舍、跨层存读续跑与逐边界回放；旧两场景归档保持一致。桌面与触屏模拟验证自然通关、按钮/连续输入、危险停机、暂停/回放和布局。截图检查三房间、装备与攀梯；记录本机渲染样本并明确设备限制。

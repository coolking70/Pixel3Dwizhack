# M02A：角色、护甲与握持试验

本步经用户要求继续 3D 方案，并优先解决盔甲辨识度与武器握持。交付为工程内独立角色试验页；现有 M01 规则版本与存录不变，不加入跳跃。

## 范围与停止点

- 一间有参照物的侧视房间、项目方块人形、布衣/皮甲/铁甲及可拆头盔、剑盾。
- 皮甲通过贴身轮廓、交叉绑带、皮裙/护膝表达；铁甲通过凸起胸板、较宽肩甲、分片裙甲、护颈和胫甲表达，不只换颜色。小尺寸和单色模式下比较轮廓。
- 握持使用手部 socket 与武器 grip 的逆变换对齐；有手掌、手指包握、护手和剑柄。盾的内侧握把与左手对应。攀爬时收起手持物，避免双手持物攀爬。
- 从已确认 CC0 的原作者资产获取少量真实骨骼动画，在构建准备阶段转换为项目命名及比例的动作数据。记录源版本、许可、散列与转换路径；不宣称任意动作包兼容。
- 独立试验支持暂停、相位定位、转身、拆装、正面/侧面查看。动作只影响试验的呈现，不调用游戏命令。
- 验证握点在动作多个相位/正反朝向下重合，资源清理、响应式布局和加载失败。视觉检查攻击极端帧，报告具体残留，不能以坐标重合代替自然握姿。

成功停止点：用户可打开试验页，直接比较甲种、看清剑柄与手的关系，运行真实导入动作并暂停检查。完整 3D 游戏呈现、战斗长动作、全装备数值系统、通用蒙皮衣甲与发布级美术不在本步完成范围。

# M16B 任务包：原生游戏 HUD 与装备背包骨架

**任务属性**：和 M16A 并行，依赖 M16C 的早期视觉接口冻结；不承担最终 45 物品造型制作。  
**输入基线与读序**：参照 M16A，并增读 `src/alpha2/Game.vue`、`Inventory.vue`、`Features.vue`、`src/room/renderer.ts`、`src/core/alpha2-view.ts`。  
**主要可写**：`src/game-ui/**`，经集成确认后少量修改 `src/alpha2/**`、`src/room/renderer.ts` 的 UI 边界。  
**禁止**：在 UI 层引入 RNG/规则时间/隐藏鉴定身份；更改装备槽位的机械定义；把 DOM 模态标记为完成的正式原生 UI。

## 产物

- 与 Three.js 游戏画面同 canvas 的 2D HUD 视图，含生命/法力/饱食/状态、深度、快捷栏、战斗日志。
- 六个可视装备槽（头、胸、腿、主手、副手、护符），中间可旋转的角色 3D 预览。
- 16 格网格背包、点击/悬停/键盘焦点/触屏长按、详情窗与合法动作菜单。
- `CanvasInputRouter` 把画布热区动作转换为受控语义命令，禁止图形组件直接写世界。
- 字形图集或像素字库：中文/英文都必须可读。开发 UI 模式可继续保留 HTML 侧栏，正常游戏体验必须能关闭它。

## 验收

1. 同一场景和命令历史，原生/旧 UI 的世界摘要完全一致。
2. UI 装备槽状态仅来自公开真实装备；穿上诅咒物品、满包、无效目标时，拒绝应正确显示。
3. 390×844、844×390、桌面宽屏至少各一套布局断言；实际触屏与输入法兼容另留复测项。
4. 鼠标、触摸、键盘能完成进背包→选物品→穿戴/取消→返回游戏；焦点与弹窗不泄漏移动指令。
5. 未鉴定物品提示、缩略图键与可见模型始终基于公开外观身份，不读取真实 definition。

**停止条件**：HUD + 装备页 + 背包骨架作为游戏画面组成部分可用，旧 α2 页面仍可玩；首批模型由 M16C 提供，未接入时标记占位不得称完成美术。

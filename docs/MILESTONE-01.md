# M01：确定性探索切片

本次从目录内的原型与架构建议建立工程。原型原样保留在 `prototypes/original.html`，新实现采用独立的小规模规则；不承诺迁移原型存档或保留全部原型物品。停止点为可运行、可保存、可逐命令重放的三层固定测试矿井。

## 规格与验收

- 整数格横版空间，三层走廊、固定梯子；视野半径 5 格，已探索地形保留，离开视野的动态实体不公开。
- 玩家移动、攻击、拾取、喝药、等待和攀爬通过唯一入口执行。移动撞敌自动攻击；攻击无目标属于耗时尝试；墙壁、无梯子、无物品等拒绝完全零影响。
- 单次玩家命令先产生玩家效果，再由唯一调度器处理耗时区间内敌人事件；同 tick 按稳定身份排序。死亡立即终止推进。离层敌人不行动，但周期时钟仍推进。不输入没有规则时间。
- 持续移动每次只提交一个动作；松开、失焦、隐藏、弹窗、危险、拒绝均清除持续意图。危险必须重新按下才能继续。现实时间只决定请求节奏，渲染不推进规则。
- 规则 RNG 使用自编 xorshift32，非零 uint32 种子。全部机械状态和 RNG 进入完整摘要。中文/英文在 UI 层翻译语义事件。
- 会话采用候选副本提交，纯查询返回分离数据。历史只记录已接受命令及逐边界摘要；同步异常不发布候选。
- 存档含快照与完整种子历史。导入使用有界严格结构校验、从种子重放每条命令并比较快照，再替换活局。旧格式明确拒绝；失败保持现局。首版限制 4096 条命令/2 MiB 文本，达到上限拒绝新命令。
- 回放从起点运行，支持任意命令位置浏览；回放只读，退出恢复活局。暂不做检查点、分支、增量摘要或 Worker。

## 验证范围

规则单测覆盖拒绝、稳定调度、查询隔离、可见性、固定种子通关、存读续跑、坏档与伪造历史、回放。输入控制器覆盖按住/松开/危险。生产构建浏览器验证键盘、指针、弹窗、存读与回放、桌面和手机尺寸。真机性能、跳跃、长动作、随机地图、模块删除不属于本阶段。

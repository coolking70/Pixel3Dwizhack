# M35 性能与设备边界

Windows桌面Headless Chromium156，ANGLE Vulkan SwiftShader软件GPU，1280×720。构建0.35.0-beta.2。真实原始样本外置于证据根m35/browser-frozen，轻量逐动作中位数/P95/峰值、draw calls、几何/纹理和堆采样在reports/m35/performance.json。

六个自然正式动作（篝火、盖风口、消骨龛、三工具）完整档与期望逐次一致，准备/接触/效果/回稳均出现，整个动画tick/revision不变。该组含导入、资源首次使用及截图准备，不能作为预热FPS基准；样本帧间隔峰476.3–1200ms。

因银砂香炉长尾，另做局部独占预热采样：普通/低画质各1次热身、3次计量，总8次命令全部完整档相等。计量阶段不截图。普通CPU提交中位1.4/P95 4.7/峰5.0ms，帧间隔63.65/1167.4/1173.2ms，draw calls350/352/352。低画质CPU1.1/4.2/5.7ms，帧间隔44.6/50.7/816.0ms，draw calls186/188/188。不同场景/版本/采样不可与M31直接做设备帧率等价对照。慢帧钳制只保证动作阶段可读，不表示卡顿已解决。

8次同检查点加载与菜单循环：geometry240、texture6稳定；CDP强制GC后堆从15,466,524到15,894,300字节，增加427,776。中位15,652,720，P95/峰15,894,300。尚未区分缓存、观测开销与泄漏，不把8次样本或稳定GPU对象数当作长期JS堆通过；M26/M31趋势继续开放。

未认证真实手机、硬件GPU、实体手柄、OS级失焦和实际浏览器150%缩放。CDP触摸验证输入分派，不代表触屏手感；853×480只作150%等效CSS视口。Firefox/WebKit本轮未重做。后续维护者优先在目标真机采集主线程/GPU时序，再决定是否扩大优化范围；本轮没有9000大矩阵、重复旧全套或虚构手机性能结论。

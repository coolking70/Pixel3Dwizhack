# Alpha 2 地牢与经济

六层，每层三段连续横向区域，边界由种子决定，标签为矿区/墓室/菌林/休息/交易。区域实际对应着色、门边界与风险层级；两条种子梯路连接相邻层构成环路。没有自由三维移动、跳台、随机无底缺口或无限世界。当前仍是有界横向连接图，不宣称任意房间形状生成。

先建立连续主路和双梯，再配置门、可直接操作的门闩、保证治疗与干粮、按深度候选敌人和可选道具。八类设施：商店、祭坛、泉水、储箱、陷阱、菌果园、营火、火区。设施之外的门/门闩不计入八种配额。至少一种无需稀有道具的路径：付出行动时间操作门闩，发现并拆除陷阱，必要时承受可恢复的环境伤害或绕梯。

买卖价以原创基础价值、BUC、强化、耐久、剩余次数和已知状态计算；先遣者略低买价，卖价为折价，商人库存和金币有限。报价提供线索但不改鉴定知识。充能服务每次花 8 金币加一次，上限为原容量。买卖双方金币守恒；祭坛收费记录在设施金币。容器货物在生成时取得唯一 id/holder，开启移至地面，背包满不丢失奖励。

投影只返回已探索区域和已发现设施，商店库存仅在邻近且视线可达时可读；未开的箱子与园地不公开奖励 id。陷阱需要搜索、照明或先遣者邻近感知，踩中会揭示。地图卷揭示地形和设施，不公开远方生物与物品。所有设施状态、门、所有权和商价相关知识均随正式历史恢复。

# Alpha 2 物品合同

数据：`src/content/alpha2.ts`。45 定义分为 8 药水、6 卷轴、5 充能法杖、8 武器、10 护甲/饰品、8 食物/工具。名字、说明和数值原创。未知类别在本局按种子打乱外观索引；同类外观编号稳定，绝不由 UI 读取真实 assignment。

实例包含 id、definition、owner、holder、位置、BUC、强化、充能、耐久、防护/烹饪与保鲜期限。owner 为 bag/ground/spent/shop/container，装备仅引用背包实例。16 格保持，重量信息不改变速度。来源记录 `original-alpha2` 见研究索引。

知识区分定义真名、实例 BUC/强化/次数和玩家备注。药剂效果实际生效后识别真名；法杖发射后显示剩余次数；投掷法杖只造成撞击、原实例落地，不扣充能也不识别真名。鉴定卷一次揭示一个实例全部知识。装备诅咒在穿戴时揭示并阻止卸下、替换、丢弃或出售；卷轴、祝福水和祭坛均可解除。

效果注册表处理伤害、状态、治疗、解除、地图、传送、召唤、开锁、食用、修理、烹饪、防腐。每个动作指定合法目标；命令先在世界副本上执行，目标或资源失败整个候选丢弃。效果中间没有持久 UI 写入。成功后的物品消耗与逻辑时间一起提交。

状态同类型同 actor 刷新期限，不叠加无限强度；到期先于同刻脉冲。火/毒等免疫抵消对应伤害或状态，物理抗性减半；金属腐蚀与生物抗性独立。耐久每少两点降低一点装备贡献，归零不删除物品或身份。强度上限 +3；营火/行军锅延长食品保鲜并消除原生菌毒，食用已变质食品仍可中毒。

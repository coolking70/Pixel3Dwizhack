# Alpha 2 交互验收矩阵

| 组合 | 成功路径 | 拒绝 / 免疫与公开边界 |
| --- | --- | --- |
| 未知药剂 | 喝作用自己；投掷对可见生物；水/酸可应用 | 不允许喝到物品；无效目标不扣物品/时间；毒抗免疫毒素 |
| 充能法杖 | 发射扣一次并识别；投掷撞击后落地 | 空充能拒绝；投掷不识别真名、不扣次数；闭门阻视线 |
| BUC 装备 | 穿戴可发现诅咒；卷轴/水/祭坛解除 | 诅咒绑定时不可卸/替换/丢/卖；失败不扣时 |
| 材质生态 | 酸蚀金属、防腐阻蚀；水灭火，湿目标更怕电 | 木/布不受金属腐蚀；火/冷/毒等按抗性；物品保护不等于生物抗性 |
| 商贸 | 有价差的买卖、充能、金币守恒 | 满包、欠款、商人资金不足、绑定物品均拒绝；报价不自动鉴定 |
| 食物 | 饱食恢复，烹饪去菌毒、延长新鲜 | 变质中毒；非食品烹饪拒绝；饥饿只按已支付时间推进 |
| 地牢设施 | 免费耗时门闩；泉水一次；容器奖励落地；主动拆陷阱 | 重复领取拒绝；未发现设施/未见库存不进入公共投影 |
| 敌人 | 预警→闪避/关门；睡眠打断；召唤有上限 | 远离或换层不受旧锁点攻击；相同截止按 id 结算 |
| 知识 UI | 已发现图鉴、搜索、转义文本笔记、状态来源 | 搜索不揭示未发现；回放只见当时知识；未知档/坏档不覆盖活局 |

实际执行证据统一见 STATUS.md，表格不是通过声明。全动作测试逐定义构造成功目标，再拒绝不可用来源；免疫只适用于有对应抗性的效果，不将食物/鉴定虚构为免疫机制。

# Alpha 2 怪物与配装

12 原型：矿穴爬行者、毒牙虫、墓室卫士、黯星咒师、掠路者、烬灵、霜壳兽、蚀铁兽、残月墓灵、胆怯拾荒者、孢群母体、星落守护者。行为为追击、锁定三格蓄力、锁格远程、攻击后撤、低血逃跑、先预警后有限召唤六类；元素、抗性、弱点和附加状态形成组合差异。召唤最多两只，全球实体数有上限；掉落与奖励只在首次死亡结算。

三配装保持：先遣者快速剑盾、相邻陷阱感知和略低购买价；破阵者慢速破甲/铁甲、修理加成；引星者法力远程与额外视野。充能法杖和投掷任何配装都可使用，职业不是内容访问限制。

敌人按整数期限/id 排序；睡眠中断准备动作、伤害唤醒；状态过期先于行动。远程与守卫意图锁定公开格，移动/关门可使攻击落空。跨层不会补发旧攻击。耐物理墓灵可用银/元素反制，普通物理仍可低效打通，不用稀有掉落作为主路钥匙。

美术沿用四种基本骨骼/体型，增加原型色彩、尺寸、背部轮廓或饰件；不是 12 套独立骨架。弓、长矛、匕首和元素剑有独立几何轮廓，统一握点与梯上收背；美术只读公开投影。

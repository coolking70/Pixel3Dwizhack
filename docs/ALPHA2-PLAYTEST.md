# 星落远征 Alpha 2 试玩说明

版本 0.15.0-alpha.2，入口 `/alpha2.html`。目标仍是深入第六层取得遗物，再回第一层左端出口；没有跳跃。

## 运行

开发目录：`npm ci` → `npm run build` → `npm run preview -- --port 4173`。打开 `http://127.0.0.1:4173/alpha2.html`。版本要求 Node 22.12+，实际验证 24.14.0。

运行分发包：解压 `fallen-star-0.15.0-alpha.2.zip`，运行 `node serve.mjs`，无需 npm 安装。端口已占用可用 `node serve.mjs 4174`。不要直接双击 HTML。

源码包：`fallen-star-0.15.0-alpha.2-source.zip`，进入 project 执行上述命令；包含源码、测试、配置、资产、配方、锁文件和文档。旧原型参考文件未打包。

## 第一局

推荐先遣者、种子 42。A/D 左右，W/S 梯子，空格攻击，F 拾取或拿遗物，Q 已识别治疗药剂，B 背包，H 指南，X 搜索，Esc 暂停；触屏使用按钮。引星者装备引星杖后用 R 消耗法力施法。

1. 入口附近有商人和保证补给。浏览不耗时，交易、换装、拾取、使用均耗时。
2. 按 B，在物品旁选饮用、投掷、阅读、发射或应用，再选作用目标并执行。未知物品可能伤害自己；无效目标不扣资源。充能法杖在包中使用，不同于 R 的法力施法。
3. 看敌人说明和锁定位置。守卫攻击三格，远程敌人锁定一格；移动或关门反制。毒牙虫不怕毒，烬灵不怕火，墓灵适合用银或元素对付。
4. 诅咒装备会绑定。用解缚卷、祝福水或付费祭坛解除。酸蚀金属，防腐保护装备；人物抗性和装备保护是两回事。
5. 搜索并拆除陷阱。火区可水灭或用抗性承受。采集食物后关注变质；营火/锅可烹饪。饱食仅随行动时间减少，不会在思考时下降。
6. 每层三片段、两条梯路。锁门旁可操作门闩，付出额外时间；不要求稀有钥匙。箱子可付钱或生命开，物品落地后需拾取。

## 知识和存档

图鉴只列本局已知真名、遇见怪物和已发现设施，可搜索。未知物品可记录最多 120 字的个人猜测，笔记不会变成真实鉴定；笔记保存进历史但不推进时间。

手动保存使用独立键 `dungeon-descent.m15`。导出 JSON 可备份/跨浏览器恢复；旧版档保留在对应旧入口，不自动迁移。完整备份包含真实世界信息以供验证恢复，请勿把检查文件当作正常探索界面。回放只见相应边界的知识，不能执行游戏动作。每局上限 4096 个成功命令、导入上限 2 MiB；若下一行动会让 Alpha 2 存档超出文件上限，会原子拒绝并保留当前可备份进度。

## 本轮范围

45 种物品、12 怪物原型、八类设施；怪物使用四类基本骨架和原型变体。地图为有限六层片段连接，不是无限任意地形。保持 16 格背包，重量仅作信息参考。弓为无限基础弹药的远程武器，本轮不引入箭矢实例；充能法杖有有限次数。音效默认关闭，设置里启用；低画质关闭阴影。

实际验证证据见 STATUS.md。自动自然路线不等于真人难度认可；真实手机、其他浏览器和长时间试玩仍需后续反馈。建议反馈种子/配装/动作边界，附导出存档并描述预期与实际，便于确定性复现。

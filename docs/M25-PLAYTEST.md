# M25 直接交互试玩 · 本地RC2

Node.js 22.12+；源码运行 npm ci、npm run dev 后访问 /alpha3.html。运行包使用 node serve.mjs，默认入口 /alpha3.html。实际验收状态见 STATUS.md，未将未执行的设备测试计为通过。

- 点击已探索地面，角色逐格前进；新敌人、受伤、异常、换层、打开菜单或失焦会停止后续行动。未锁门在通行前自动打开，锁门进入情境选择。
- 点击敌人尝试靠近并攻击；点击地面物品靠近拾取；点击门、梯子、设施查看或执行公开可用动作。收费和强开操作需要明确确认。
- 背包有六装备槽和十六格；点非空格进入独立3D详情，可拖动模型。动作再选择自身、物品或世界目标，最后确认。未知效果显示可尝试，不揭示秘密定义。
- 自由投掷限本层已探索且可见的1–5格，药瓶有效投掷后破碎；其他物品落在实际碰撞位置。投掷法杖只作物理撞击，不消耗充能。准备、接触、效果、回稳只负责呈现。
- A/D 或方向键移动，W/S 爬梯，Space 攻击，B 背包，H 指南。Tab/Shift+Tab切换焦点，Enter操作，目标模式方向键切换目标，触屏也可点左/右目标按钮；相机会纳入已选公开目标，Escape返回。手柄方向/摇杆使用相同意图，A确认、B返回、X背包、Y攻击、Start暂停；实际实体手柄覆盖另列验收记录。
- 菜单提供保存、读档、导入导出、回放和显示选项。保存为浏览器本地数据，换浏览器前导出JSON。旧 Alpha 2 存档请到 /alpha2.html 加载，不会自动升级规则。

历史回退：/alpha2.html?ui=buttons 为 M20 原生按钮布局，?ui=legacy 为外围 DOM 布局。六旧规则入口保留。新旧规则和存档相互隔离，不以更换文件名转换存档。

源码回归：`npm run check` 与 `npm run test:e2e` 检查规则/构建及历史浏览器。另装 `npx playwright install chromium firefox webkit`，启动 `npm run preview -- --port 5174 --strictPort`，运行 `npx playwright test --config playwright.m25.config.ts` 检查新直接交互；可用环境变量M25_URL指向其他生产预览端口。两配置分开计数，不以旧94项代替新流程。浏览器安装或启动失败必须登记，不能算用例通过。

协议：UI 只发送语义命令/读取公共投影；Alpha 2 模拟拥有新物品/状态/知识/设施，渲染的旧视图适配仅为派生数据。世界复制后结算，失败不发布。公开目标只含可见生物、邻近设施、背包物品和自己，远程需要视线。消息不透露隐藏身份，笔记是玩家猜测而非真名。非装备投掷具有损失/试探代价，法杖投掷不扣充能但落地且敌人可反应。

到期固定顺序：状态清除 → 法力/饱食 → 周期伤害 → 敌人 id。状态同类刷新不无限叠强度；耐久降低装备贡献但不销毁身份。16 格背包保留，重量用于信息展示，本轮不追加负重速度规则。物品/怪物数值、美术和文本原创；受限 JSON 模型合同保留，不宣称通用 FBX 重定向。

设施选定行为：商店有限库存/资金与买卖价差；祭坛花金解除指定装备诅咒并揭示 BUC；泉水一次恢复；箱子付金或付血打开；陷阱可主动搜索发现并拆除；资源园有限食物；营火烹饪/消毒食品；火区可水灭火或防护通过。门/拉杆为已有连接设施，不计入八类新设施。

停止条件：本地 Alpha 2 功能、可执行验证和分发完成。真人确认内容密度/公平性需要后续试玩，不能由自动路线冒充；真实手机和其他浏览器无法测试时记录缺口。只有重大产品决策暂停；不自动部署或采购。

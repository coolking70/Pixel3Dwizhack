# 星落远征 Alpha 试玩说明

版本：0.10.0-alpha.1。目标：深入第六层，击败守护者，拾取星落遗物，返回第一层左端出口。没有跳跃或需要跨越的缺口。

## 启动

开发目录：`npm ci` → `npm run build` → `npm run preview -- --port 4173`，打开 `http://127.0.0.1:4173/alpha.html`。

分发包：解压 `releases/fallen-star-0.10.0-alpha.1.zip`，在解压目录运行 `node serve.mjs`，打开相同地址；若端口占用，运行 `node serve.mjs 4174` 并访问 4174。需要 Node.js 22.12+，当前验证环境为 24.14.0。包内服务器不需要 npm install。

## 第一局

1. 推荐先遣者，种子 42。先在门厅走动并收起药剂；松开按键后可以自由思考。
2. 看见敌人时先观察预警。空格近战，也可以向相邻敌人移动来攻击。守卫打三格区域，咒术师只打锁定格；移动躲避也会消耗时间。
3. 两条梯路都可探索。有锁门闩可以寻找同层拉杆，也可以从上一层另一条梯路绕行；如果梯口被敌人占据，换另一个入口。
4. B 打开背包，装备拾到的衣甲；浏览不耗时，穿脱和饮用会耗时。未知药剂可用卷轴鉴定。补给箱可支付金币或生命开启，物品仍需拾取。
5. 拿到遗物后看小地图，返回第一层最左侧。手动保存或导出存档，以便下次继续。

## 三种起始配装

| 配装 | 特点 |
| --- | --- |
| 先遣者 | 剑攻击耗时 10，防御均衡，适合打完迅速调整位置 |
| 破阵者 | 重锤攻击耗时 20，抵消 4 点敌方护甲，行动较慢 |
| 引星者 | 装备法杖时 R 施法，射程 5，耗费 3 法力与 18 tick；法力每 20 tick 回复 1，近战较弱 |

法术伤害独立于装备的近战攻击值；当前基础 14，带少量波动。界面中的行动费用是游戏时间，不是需要等待的现实秒数。暂停和打开面板不会撤回已经接受的行动。

## 操作

| 输入 | 操作 |
| --- | --- |
| A / D 或左右键 | 行走，长按可连续移动；遇险会停止 |
| W / S 或上下键 | 梯口攀爬 |
| Space / R | 近战 / 持杖施法 |
| F / Q | 拾取或附近机关 / 已知治疗药剂 |
| B / H / Esc | 背包 / 指南 / 暂停 |

触屏按钮位于场景下方；门、拉杆和补给箱在“附近机关与补给”中操作。设置可开启音效或低画质。保存写入当前浏览器；导出 JSON 才能带到另一个浏览器。回放只读，返回当前进度后继续。M06 入口及其存档独立保留在 `/adventure.html`。

## 反馈重点

请记录种子、起始配装、楼层，以及最明显的问题：敌人预警是否看懂、衣甲能否分辨、攻击是否对得上目标、绕路是否有价值、药剂是否过多或不足、触屏是否顺手。规则或存档问题可附导出的 JSON；卡顿可附设备和浏览器版本。

自动自然路线通过不等于真人难度已定稿。当前完成 Chromium 桌面/触屏模拟以及本机 NVIDIA 硬件渲染验证；真实手机、Safari/Firefox 和更长游玩反馈留待后续。原生商店安装包、在线服务和任意 FBX/glTF 自动导入不在本版范围。

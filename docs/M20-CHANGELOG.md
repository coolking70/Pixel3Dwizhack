# 0.20.0-rc.1 变更记录

相对0.15.0-alpha.2完整源码，包含M16–M20的本地开发成果。发布验收状态以STATUS.md为准，版本名不代表所有设备通过。

## 玩家可见变化

- Alpha2默认使用同一游戏画布中的开局、HUD、六槽装备、16格背包、动作/目标、交易、地图、图鉴/笔记、日志、存录与设置。保留文件选择、IME/无障碍桥接和图形失效兜底。旧DOM开发回退为`?ui=legacy`。
- 全部45公共物品外观具有原创独立几何与三档真实LOD；地面、背包、商店和佩戴复用同一资源。未知药剂/卷轴/法杖/饰品仍按本局随机公开外观显示，鉴定不会暴露另一模型身份；四种食物有变质覆盖层。
- 拾取、推/拉门、拉杆、开箱及饮用、阅读、施杖、投掷、进食、应用、穿戴/卸下分准备、接触、效果、回稳演出。手掌、嘴、工具和环境使用真实接触点；卷轴展开、杖首发射、投掷飞行。袋内执行暂显场景，结束后返回背包。
- 暂停、失焦、存读、回放、低帧与WebGL失效会结清表现，恢复图形不会补交行动。修复HUD键盘不可达、触屏长按提前提交、Space攻击被悬停按钮覆盖等问题。

## 开发与验证

- 新增无渲染正式命令代理、三策略分层统计、失败逐步回放、输入散列冻结、seed聚类配对比较与探索/禁物品/保留起始武器的策略消融。M17基线实际9000配置已完成，最终M20配对结果另见reports/balance/M20-COMPARISON.md。
- 模型配方生成与135GLB审计进入CI和本地release门禁；完整源码分发包含assets-src原创配方及轻量平衡报告。新增同画布浏览器、接触、中断、异步资源和图形生命周期测试。
- 为降低重型自然路线测试争抢，Vitest最多使用4个可用worker；未修改旧断言、黄金夹具或时间预算。性能报告分别记录真实硬件和软件渲染的中位/P95/峰值与内存，不混用Node数据。

## 兼容与保留项

六历史规则身份、命令版本、旧存档键、机械内容、规则随机与黄金档不变；24个core/content/session文件保持M15散列。产品版本提升不触发存档迁移。旧M15两个分发包原样保留，没有提交、推送、部署或采购资产。

软件渲染仍有明显尾延迟；真实手机、Safari/Firefox、GPU显存、长时压力、系统输入法/读屏矩阵尚未覆盖。默认窄装备预览下部分盾缘有裁切；角色可旋转，后续应按装备包围盒适配相机。现有规则没有高架物品，不将pickupHigh或跳跃伪装成已实现。详细证据和责任人见M20-ACCEPTANCE.md、M20-PERFORMANCE.md。

# M31 本地试玩

运行包解压后，Node.js 22.12+ 执行 `node serve.mjs`，打开 http://127.0.0.1:4173/alpha5.html 。不要直接双击HTML。源码：`npm ci`、`npm run dev`，打开开发服务器的 `/alpha5.html`。可用 `npm run check:m31` 执行本轮精简门禁；历史完整测试 `npm run check` 保留。

A/D移动，W/S爬梯，空格攻击，F拾取，B物品，H指南。J选落点，左右选择，Enter确认，Esc取消；点击可见格地面上方的空中区域也可跳跃。手柄A在世界中瞄准跳跃，在菜单/物品目标中确认。界面、设备失焦和动画均不自行推进规则时间。

建议新手选先遣者，行至首层x6，跳至x8跨过x7可见陷阱，拾取并继续；也可先拆陷阱再走。跳1格16tick、2格22tick，迟缓翻倍；负重>40、睡眠、混乱禁止。门和生物阻挡整条路径，低横梁只可跨越，不能作为落点。落地危险生效，敌人获得完整行动成本。

腐菌区可封菌床再战，或用水/净菌摇铃处理；使用火焰须考虑近身灼伤。工坊可断电破坏维护蛛维修循环，用调谐器修甲或留充能断电；低横梁可跳过或拆除。物品详情和图鉴提供中英文说明。未知祝福/诅咒和充能仍需本局鉴定。

新存档键 `dungeon-descent.m31`，与M26独立。旧档在对应旧入口打开，不伪装迁移。完整存档可导出/导入和回放；保存必须手动操作，换浏览器前请导出。

浏览器精简验收：`npm run build`；另终端 `npm run preview -- --port 4231 --strictPort`；`npx playwright test --config playwright.m31.config.ts`。本轮只覆盖桌面Chromium和模拟手柄事件，未认证实体手机/手柄。第三生态包、垂直拓扑扩展、M26长期JS堆增长归因留后续，见验收记录。
